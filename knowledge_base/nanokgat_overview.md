# NanoKGAT 与图注意力在结合位点预测中的角色

NanoKGAT 是一类将纳米抗体序列/结构特征与图神经网络（GNN）结合的模型族名称（示例命名）。在典型流程中，抗体与抗原被表示为残基级图：节点为氨基酸，边为空间邻接或序列邻接；通过注意力机制学习节点重要性，从而输出可能的结合残基排序或概率。

## 与通用语言模型的关系

大语言模型擅长定义、方法对比与流程解释；对具体蛋白结构的定量预测应交给专用模型（如 NanoKGAT）以减少幻觉。本智能体在检索相关性不足时，由 LLM 判断意图：定义/对比类直接回答，预测/可视化类调用 NanoKGAT。

## 可视化

PyMOL 常用于展示预测得到的结合位点：可将高置信度残基着色为高亮，并加载抗原-抗体复合物或对接构象。若部署了配套查看服务，系统可在预测后返回可点击的可视化入口链接。
