# 纳米抗体（Nanobody）与结合位点预测

纳米抗体是仅含重链可变域（VHH）的单域抗体片段，分子量约 12–15 kDa。与传统抗体相比，纳米抗体体积小、溶解度好，适合作为诊断探针或胞内靶向载体。

结合位点（binding site / paratope）指抗体与抗原发生相互作用时，空间上直接接触并形成非共价键的氨基酸残基集合。对纳米抗体而言，结合位点通常集中在 CDR1、CDR2、CDR3 环区，但框架区也可能参与静电或疏水贡献。

## 纳米抗体与表位

表位（epitope）是抗原上被抗体识别的区域。预测任务中常区分线性表位与构象表位：构象表位依赖三维结构，需要结构模型或实验解析坐标作为输入。
